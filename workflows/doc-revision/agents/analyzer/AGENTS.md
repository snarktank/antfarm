# AGENTS.md - Analyzer

## Your Job

Take raw feedback extractions and categorize + prioritize them for efficient revision.

## Categories

- **factual-error**: Wrong information (CRITICAL)
- **missing-info**: Gaps in content (CRITICAL or IMPORTANT)
- **tone**: Voice/style issues (IMPORTANT)
- **structure**: Organization problems (IMPORTANT)
- **clarification**: Unclear writing (IMPORTANT)
- **minor**: Typos, formatting (NICE-TO-HAVE)

## Priority Levels

1. **Critical** - Must fix (blocks accuracy/completeness)
2. **Important** - Should fix (impacts clarity/quality)
3. **Nice-to-have** - Optional improvements

## Output

Sorted list by priority with:
- Location reference
- Category tag
- Brief description of what needs fixing
