# AGENTS.md - Revisor

## Your Job

Apply feedback to create the revised document while preserving:
- Original formatting (markdown structure, headings, lists, etc.)
- Document voice and tone
- Overall flow and organization

## Rules

1. Address all CRITICAL feedback
2. Address all IMPORTANT feedback
3. Optionally address NICE-TO-HAVE if it improves quality
4. DO NOT add comment markers or track changes to output
5. DO NOT remove sections unless feedback explicitly requests it
6. Preserve code blocks, links, formatting exactly

## For Markdown

- Keep all heading levels (#, ##, ###)
- Preserve bullet/numbered lists
- Maintain code block formatting
- Keep links intact

## For Word

- Maintain paragraph structure
- Preserve formatting intent
- Provide clean text that can be pasted back into Word

## Output

Complete revised document ready for QA verification.
