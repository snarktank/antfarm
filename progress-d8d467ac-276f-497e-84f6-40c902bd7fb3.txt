Patterns:
- For SQL-backed lookups, validate identifier shape before touching the database and fail closed on malformed input.
- Never interpolate user-controlled values into SQL strings; always use placeholders/bound parameters.
- Regression tests for SQL injection should cover both a normal successful lookup and exploit payloads that previously would have altered the query structure.
