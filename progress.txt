## Codebase Patterns
- Workflow crons created dynamically when runs start via `ensureWorkflowCrons()` in `src/installer/agent-cron.ts`
- Cron creation logic checks for existing crons to avoid duplicates
- Tests use `node --test tests/<file>.test.ts` (node:test + node:assert/strict)
- Workflow specs define agents and steps in `workflows/<name>/workflow.yml`
- Agent provisioning happens in `src/installer/agent-provision.ts`
- Build: `npm run build` runs `tsc -p tsconfig.json` + copies HTML + chmod
