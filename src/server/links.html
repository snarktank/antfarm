Integración con el bot

Envía un POST desde OpenClaw o cualquier servicio dentro de la red privada (Tailscale) al puerto que estés usando.

POST http://localhost:5000/api/links Content-Type: application/json { "url": "https://example.com", "title": "Nombre", "category": "Tarea", "notes": "Notas opcionales" }

Los datos se guardan en ~/.openclaw/antfarm/links.json y solo se expone en la red privada.
